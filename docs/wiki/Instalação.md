# Instalação

## Linux

```bash
wget https://github.com/rubenslyra/AudioLabEditor/releases/download/v1.2.0/audiolab-editor-linux-x86_64
chmod +x audiolab-editor-linux-x86_64
```

## Windows

Baixe `audiolab-editor-windows-x86_64.exe` da [release v1.2.0](https://github.com/rubenslyra/AudioLabEditor/releases/tag/v1.2.0)

## macOS

Baixe `audiolab-editor-macos-x86_64` da release

## Dependências de IA

Abra a aba desejada no app e clique em **Baixar runtime de IA**.
