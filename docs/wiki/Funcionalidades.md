# Funcionalidades

- **Captura de Mídia** — download via yt-dlp (MP4, WebM, MP3, WAV, FLAC, etc.)
- **Corte de Áudio** — corte preciso com waveform, múltiplos formatos
- **Separação de Stems** — isolamento de vocais/instrumentos via Demucs (IA)
- **Transcrição** — áudio para texto com faster-whisper (SRT + TXT)
- **TTS** — síntese de voz com Microsoft Edge TTS (18 vozes)
- **Editor de Vídeo** — corte com CRF + x264
